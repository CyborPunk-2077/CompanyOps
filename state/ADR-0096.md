# ADR-0096 — Twinframe Shows Truthful Aggregate Endpoints, Not Invented Trajectories
Status: Accepted

The frozen chronology projection currently provides authoritative aggregate endpoint observations plus deterministic event marks, but not intra-run KPI time-series observations.

Twinframe therefore renders endpoint values, paired harm/CI/tolerance, scenario context, and event chronology. It must not interpolate or draw synthetic KPI trajectories. Longitudinal metric curves require explicit future runtime/evaluation evidence.
