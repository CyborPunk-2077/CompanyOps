# ADR-0094 — Web Result Experience Consumes Sealed Backend Projection
Status: Accepted

The CompanyLab/CompanyOps result UI consumes the validated `companylab.projection/0.1.0` output generated by the backend projection layer. React may format and lay out values but must not recompute KPI observations, paired harm, confidence intervals, assertion status, BusinessVerdict, ReleaseRecommendation, or gate truth.

The flagship vertical slice uses a deterministic generated TypeScript projection fixture sourced from Projection Golden v1 until the live API transport is wired end-to-end.
