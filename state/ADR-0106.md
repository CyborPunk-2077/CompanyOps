# ADR-0106 — Persisted Child Run IDs Are Experiment Scoped
Status: Accepted

Custom/persisted experiment child run IDs include a deterministic experiment-identity prefix before pair identity. This prevents run primary-key collisions when multiple experiments execute the same semantic pair index in one workspace. Historical default/reference run IDs remain unchanged, so earlier simulation/evaluation/projection goldens stay immutable. Execution Golden v2 pins the new persistence semantics.
