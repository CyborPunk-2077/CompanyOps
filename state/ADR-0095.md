# ADR-0095 — Result Context Is URL State and Server-First
Status: Accepted

Lens, assertion, evidence-joint, representative-pair, and replay-cursor selection are encoded in URL query state for the PACK-031/032 result experience.

This preserves shareable/deep-linkable context and keeps the result composition server-first. A client component is not introduced merely to switch result context; the existing ThemeControl remains the only product-shell client island at this checkpoint.
